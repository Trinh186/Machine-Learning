HAI FILE TEST THEO CACH THAY - BAN DIEU CHINH CHO DU AN CUA NHOM

1. Chep test_login.py va test_userDAO.py vao Machine-Learning/ui_app/tests/
2. Mo terminal tai Machine-Learning/ui_app, kich hoat moi truong Python da cai requirements.txt.
3. Chay tung file:
    python -m tests.test_login
    python -m tests.test_userDAO
4. Co the chay app day du nhu cu:
    python main.py
5. Hai file nay la CHAY THU THU CONG. Unit test tu dong da co tests/test_auth_service.py.
6. KHONG doi ten/di chuyen ui_app/main.py.
7. test_userDAO.py khong ghi cung mat khau, khong in password_hash.
8. Yeu cau ui/LoginMainWindow.py, ui/LoginMainWindowEx.py, auth/ va .env da duoc cau hinh.
